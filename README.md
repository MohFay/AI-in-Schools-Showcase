# AI in Schools — Tools for Learning, Not Shortcuts

A responsive informational website for the AI in Schools Showcase on October 14, 2026 at The Ohioan in Lewis Center, Ohio.

## Open locally

1. Extract the ZIP file if you downloaded the package.
2. Open `index.html` in a current browser.
3. Use the navigation to visit the five career pages and Sources page.

The site is static HTML, CSS, and JavaScript. It does not require a server, API key, package manager, or external JavaScript library.

## Files

- `index.html` — Home page and statistics overview
- `it.html` — IT and coding
- `engineering.html` — Engineering
- `health.html` — Health
- `business.html` — Business and marketing
- `media-arts.html` — Media arts
- `sources.html` — Sources and broader employment context
- `styles.css` — Responsive design, light/dark themes, accessibility styles
- `script.js` — Theme toggle (saved to localStorage), mobile navigation, subtle reveal animations

## Notes

- Employment figures are labeled with the BLS projection period (2025–2035). The recent-graduate unemployment figure is attributed to Stanford SIEPR and is not described as an AI-caused outcome.
- The site uses the teacher interview supplied in the PDFs. It does not invent career-specific quotes that were not included in the source material; those are marked as placeholders.
- External source links require an internet connection. The website itself can be opened offline.
- The static website is ready for use as a prototype or as a source design to recreate/import in a website builder such as Lovable. I have not published it to a Lovable project or hosting account.
